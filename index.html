01

SeatSync

An event-booking app where each booking is a conditional seat decrement inside a PostgreSQL transaction, so concurrent requests queue on the event’s row lock and an event cannot be oversold. Load-tested at 300 simultaneous bookings for 30 seats: exactly 30 succeeded and 270 were rejected with HTTP 409. Fixed a race where an admin changing an event’s seat count could erase concurrent bookings, using a compare-and-set update; 60 Jest and Supertest tests run in CI against a separate test database.
